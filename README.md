# Playlist Launcher

A simple console-based Python application that helps users create, manage, save, and play video playlists.

## Description
This program allows you to create multiple playlists, add videos to them, save everything to text files, view the playlists, and open any video directly in your default web browser.

It was built as a learning project to practice object-oriented programming, file handling, and menu-driven interfaces in Python.

## Features
- Create playlists with name, description, rating, and multiple videos
- Save and load playlists from text files
- Display all playlists with detailed video information
- Open videos instantly in the default web browser
- Simple input validation and menu system

## Requirements
- Python 3.x
- No external libraries needed (uses only built-in `webbrowser` and `os` modules)

2. Open a terminal/command prompt in the project folder.
